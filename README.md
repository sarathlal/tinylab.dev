# tinylab.dev

Source for [tinylab.dev](https://tinylab.dev): plain-language tutorial tracks (DevOps, Linux, Python, Go, Rust, React) and a daily AI news brief, built with Jekyll.

- `bundle install && bundle exec jekyll serve` to run locally.
- Track structure lives in `_data/curriculum/`; `python3 scripts/scaffold.py <track>` generates stub pages from it.
- See [CONTRIBUTING.md](CONTRIBUTING.md) for site mechanics and [CLAUDE.md](CLAUDE.md) for the writing standard.
