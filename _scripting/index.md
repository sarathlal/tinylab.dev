Most of the day-to-day work in operations is small programs that glue bigger tools together: a script that checks certificates, a one-liner that summarises a log, a Python tool that calls an API. **Scripting** is that skill, and Git is how you keep and share what you write.

This subject covers Bash well enough to write scripts you can trust, the text-processing tools you will use daily, Python for the jobs Bash is bad at, and the parts of Git you actually need.

## How to use this subject

- **Read in order** — each page builds on the one before.
- **Run the commands** — every page has a hands-on part; that is where the understanding comes from.
- **Check yourself at the end** — each page closes with questions whose answers are in the page.
- **Stop at the depth you need** — pages are tagged <span class="badge badge-foundation">foundation</span>, <span class="badge badge-intermediate">intermediate</span> and <span class="badge badge-advanced">advanced</span>.
