**Terraform** lets you describe infrastructure — networks, servers, databases, Kubernetes clusters, DNS records — in text files, then creates, changes and deletes the real thing to match. Because the description is a file, it can be reviewed, versioned, tested and recreated exactly.

This subject starts from the first resource and builds to modules, remote state, environments, pipelines and policy. It covers both Terraform and its open-source fork OpenTofu, which share the language.

## How to use this subject

- **Read in order** — each page builds on the one before.
- **Run the commands** — every page has a hands-on part; that is where the understanding comes from.
- **Check yourself at the end** — each page closes with questions whose answers are in the page.
- **Stop at the depth you need** — pages are tagged <span class="badge badge-foundation">foundation</span>, <span class="badge badge-intermediate">intermediate</span> and <span class="badge badge-advanced">advanced</span>.
