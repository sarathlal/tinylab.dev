**Linux** is the operating system that runs almost every server on the internet, every container, and the machines underneath every cloud service. If you work with software that runs anywhere other than a laptop, you will work with Linux — usually through a text terminal, on a machine you cannot see.

This subject teaches Linux the way an operator meets it: files and permissions, users and processes, services that start on boot, memory and disks, and the tools for finding out why something is slow or broken. The last section goes under the surface into the kernel, for when you want to know *why*.

## How to use this subject

- **Read in order** — each page builds on the one before.
- **Run the commands** — every page has a hands-on part; that is where the understanding comes from.
- **Check yourself at the end** — each page closes with questions whose answers are in the page.
- **Stop at the depth you need** — pages are tagged <span class="badge badge-foundation">foundation</span>, <span class="badge badge-intermediate">intermediate</span> and <span class="badge badge-advanced">advanced</span>.
